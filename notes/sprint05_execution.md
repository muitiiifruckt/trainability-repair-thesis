# Спринт 05: уточнения исполнения до запуска

Дата: 2026-11-16. Научный дизайн — [sprint04_common_batch_prereg.md](sprint04_common_batch_prereg.md). Горизонт, seeds, цели, число ячеек и критерий сохраняются.

Runner `causal_trainability/common_batch.py`: один поток, CPU. L2 по слоям и Adam на updates 0/8/16, L3 на 0/8/16, начальная θ⁰ и полный общий batch отдельно с SHA. Метрики representation на фиксированном reference на этих же точках. Общий формат Telemetry; snapshots хранятся в одном небольшом bundle через TelemetryStore и записываются при закрытии. На одной ячейке сохраняется не более трёх snapshots.

Первые два набора градиентов и порядок всех 16 minibatches записываются через optimizer pre-step hook. Это hook наблюдения; исходный PPO.learn не переписывается. Frozen body имеет requires_grad=False; optimizer хранит исходную группу параметров, Adam state для frozen параметров не создаётся.

Timing измеряет фактическую ячейку целиком: построение PPO/model, установка тела и голов, исходная и конечная оценка цели, обучение, начальный/final лог, L3, закрытие writer, итоговое сохранение weights/Adam. Подготовка общего batch и чтение source вне таймера, поскольку выполняются один раз на batch, а не на ячейку. Этот отчёт относится к стоимости ячейки; стоимость генерации данных измеряется отдельно. Off сохраняет обязательный итоговый checkpoint и результат, но не L2/L3.

Калибровка: development s0, repeat 0, seed namespace `s05-calibration` вместо научного `s04-common`, без интерпретации gain. Четыре ячейки, по одному прогреву on/off, три пары в порядке on/off, off/on, on/off. Все 32 запуска сохраняются. Mean и median overhead ≤5% в каждой ячейке; веса, Adam, PPO/global RNG и batch до/после логирования совпадают. Объём теста не увеличивается ради допуска.

Output roots: `runs/causal-trainability/sprint05_calibration_v1_20261116` и `runs/causal-trainability/sprint05_common_v1_20261116`. При прерывании завершённая группа history/repeat сохраняется; незавершённая остаётся в attempts, следующий запуск создаёт новую попытку с теми же seeds. Manifest при resume сверяется с freeze; научный запуск проверяет PASS калибровки того же кода и протоколов. При FAIL весь научный запуск блокируется.

Отсутствие информативного batch отмечается по протоколу без замены seeds. Конечная научная сводка всё равно включает сырые результаты всех 72 ячеек, если вычисления конечны; nonfinite — техническая остановка и отдельный статус. Анализ читает исходы с проверкой SHA и пересчитывает gain из сохранённых before/after, не доверяя готовому контрасту.
