# Спринт 06: технический пилот matched policy

Дата: 2026-11-18. Freeze кода и протокола: `a1b57a0`. [Данные](../research/results/sprint06-match/pilot.json), протокол [sprint06_match_prereg.md](sprint06_match_prereg.md).

Семь синтетических/регрессионных проверок прошли. Затем выполнены шесть технических веток: development s0/s1 × neither/reset/matched, по 2048 steps. Return/AUC научной серии не оценивались; интервалы по двум историям не строятся.

Пилот PASS: matched сохраняет raw параметры старого actor; начальные logits/value и первый rollout/targets/PPO RNG точно совпадают с reset. Frozen anchors неизменны и не имеют grad/Adam state. Продолжение последнего обновления из checkpoint побитово совпало. Синтетическая проверка logging on/off также прошла; overhead пилотом не разрешается, для него предусмотрена отдельная калибровка.

На общем первом minibatch до clipping градиенты голов совпали побитово, а градиенты тела различались. Например, норма conv на s0: reset 7.46189, matched 7.91988; норма actor в обоих 1.14649, critic 15.91927. На s1 conv 4.55426 против 4.33166; actor 1.17039 и critic 8.23260 совпадают. Это техническое подтверждение равных выходов при различной параметризации, а не измерение пластичности. После общей обрезки нормы различия могут затронуть все обновления.

Следующий gate — отдельные logging on/off пары по всем трём ячейкам при полном горизонте 131072 steps. Без PASS научная очередь не запускается. Исключение для лабораторного теста спринта 05 сюда не переносится.

Итог последующих этапов: отдельная калибровка прошла без исключений, научная серия завершена; [научный результат](sprint06_results.md). Выводы пилота не подменяли её критерий.
