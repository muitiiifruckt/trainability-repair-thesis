# Правила проекта для агентов

Проект: diagnosis-guided repair of trainability in deep RL. Отвечать и писать документы по-русски; термины и идентификаторы — как в оригинале.

## С чего начинать каждую сессию

1. `sprints/README.md` → текущий спринт (последний `sprints/sprint-NN/plan.md`): цель, задачи, критерии готовности.
2. `research/NEXT.md` — живое состояние кампании, команды запуска/остановки, реестр гипотез.
3. `research/decisions.md` — принятые решения (новые сверху вниз по датам).

## Работа спринтами

- Спринт = 1 неделя. Каждый спринт живёт в `sprints/sprint-NN/`:
  - `plan.md` — пишется в начале по `sprints/TEMPLATE_plan.md` **на основе `review.md` предыдущего спринта**;
  - `review.md` — пишется в конце по `sprints/TEMPLATE_review.md`: что сделано (со ссылками на файлы/коммиты), что нет и почему, выводы, что переносится.
- В течение спринта отмечать статус задач прямо в `plan.md` (`[ ]` → `[x]`, или `[~]` — частично, с пояснением). Новые задачи добавлять в раздел «Добавлено в ходе спринта», а не переписывать исходный план.
- Следующий план не начинается, пока не написан review текущего.
- Научные выводы в review — только с числами из файлов; неопределённое помечать «неопределённо». Отрицательные и неопределённые результаты записываются так же подробно, как положительные.

## Жёсткие правила исследования

- Не менять `experiments/` и `configs/`, пока идёт кампания: SHA кода зафиксирован в `runs/<program>/dependency_manifest.json`. Правки — только для новой кампании с новым `output_root`.
- Единица независимости — полная история обучения (`trajectory_id`); повторы одной истории не независимы. Интервалы не показывать при < 5 историях.
- Reserved-игры (`freeway`, `seaquest`) закрыты до заморозки протокола.
- Большие артефакты (checkpoints, replay, `runs/`) в Git не коммитить.
- Ресурсы ограничены (~14 ГБ RAM, кампания занимает 2 workers): тяжёлые запуски рядом с кампанией запрещены; субагенты — 1 поток, < 1 ГБ RAM.

## Личные материалы

Пояснительные материалы для студента (шпаргалки, подготовка и записи встреч с руководителем) хранить в `personal/` — папка в `.gitignore` и не публикуется. В git идут только исследовательские артефакты: код, данные-сводки, протоколы, обзор, решения, спринты.

## Субагенты и дебат

Пары «Proposer / Skeptic» работают по `research/debate/PROTOCOL.md`, пишут в `research/debate/log.md` и ведут `handoff_*.md`. При ~150k токенов контекста агент обновляет handoff и завершается; преемник стартует по handoff-файлу.
