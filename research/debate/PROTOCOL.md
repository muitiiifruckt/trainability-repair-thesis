# Дебат двух исследователей (A — «Proposer», B — «Skeptic»)

Общий журнал: `research/debate/log.md` (только дописывать в конец, формат `## [A|B] <время> <тема>`).
Каждый ход: утверждение + доказательство (файл/скрипт/число с путём) + что опровергло бы.
Skeptic обязан пробовать опровергнуть последнее утверждение Proposer'а (альтернативные объяснения, утечки, независимость единиц,
множественные сравнения) и воспроизвести его число независимо. Proposer обязан отвечать экспериментом, а не риторикой.
Принятые идеи (обе стороны согласны) -> `research/debate/accepted.md`; отвергнутые -> `rejected.md` с причиной.

## Жёсткие границы
- Не менять `configs/`, `experiments/`, `runs/`, `research/results/minatar-repair-20261007/` (идёт живая кампания).
- Лёгкие эксперименты: 1 поток (`torch.set_num_threads(1)`), RAM < 1 GB, каждый запуск < 10 минут; свои артефакты — только в `research/debate/` и `scripts/debate_*.py`.
- Данные кампании читать можно (runs/minatar-repair-20261007/outcomes.jsonl, diagnostics.jsonl) только на чтение.
- Числа только из файлов; не выдумывать результаты; неопределённое помечать «неопределённо». Reserved-игры freeway/seaquest не трогать.
- Не коммитить (коммитит координатор). Писать по-русски.
