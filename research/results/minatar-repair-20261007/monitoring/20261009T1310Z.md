# Первый online screen: все 96 веток

**Что проверено.** Breakout и Asterix, source seeds 0–2, nominal ages 50k/200k, четыре repairs, continuation repeats 0/1, по 50k transitions. Полные 96 jobs и 24 панели, шесть полных histories. Проверены уникальность jobs/actions, matched continuation/evaluation seeds и бюджеты. Failures и нечисловых finals нет. Все scientific code hashes совпадают с dependency manifest; runtime код и конфигурация не менялись.

**Зачем.** Установить, есть ли вообще различия между вмешательствами в online RL и на каком уровне они воспроизводятся, прежде чем обучать selector.

**Результат.** Средний effect Adam/head/joint относительно continue: Breakout −0.500/+0.071/−0.696, Asterix +0.338/−0.004/+0.771. Средний Adam и joint effect отрицателен в каждой из трёх Breakout histories и положителен в каждой из трёх Asterix histories. Head effect неоднороден внутри обеих игр. Наблюдаемый отрицательный final effect joint: 10/12 панелей Breakout, 3/12 Asterix; это описательные counts, без поправки на evaluation noise. Interaction среднего по history: Breakout −0.563/+0.462/−0.700, Asterix +0.525/+0.088/+0.700. Ранний кандидат на универсально отрицательное взаимодействие не подтверждён.

**Объяснение и ограничения.** Различие game contexts пока проще объясняет наблюдение, чем индивидуальная диагностика деградации. Причина не установлена: возможны step-size response, взаимодействие состояний, старые targets или occupancy feedback. Reset не является измерением «неисправности» соответствующей подсистемы. Три histories/game недостаточны для population confidence statements, поэтому автоматические bootstrap intervals в REPORT не используются. Два возраста и два repeats усредняются внутри source history. Средний immediate head/joint drop −3.058 в Breakout и −0.850 в Asterix; большой recovery gain после разрушения функции не означает лучший final return.

**Решение.** Классификация пока **неопределённо**. Зафиксировать natural screening как отдельный результат текущего code hash, выполнить предусмотренные fixed-TD, timestep/epsilon/LR controls и independent repeats 2/3. Обучение selector и reserved transfer не открывать по одному game contrast. Никакие scientific гиперпараметры не выбраны по этому срезу. Stress strata по-прежнему проверяются отдельно согласно программе и completion audit.
